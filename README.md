# Mapsachusetts

Mapsachusetts is a lightweight geospatial project exploring Massachusetts using Python, GeoPandas, DuckDB, and Folium. This initial commit sets up the basic structure for data ingestion and future mapping work.

## Quickstart
``pip install -r requirements.txt``<br>
``python scripts/main.py``

## Structure
- `data/raw/` — raw GIS files (GeoJSON, Shapefile, CSV)
- `data/clean/` — cleaned, normalized outputs
- `scripts/` — pipeline entry point
